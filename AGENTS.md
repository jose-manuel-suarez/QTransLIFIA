# QTransLIFIA — Contexto persistente

> Este archivo se carga automáticamente en cada sesión del agente. Equivale a `MUSE.md` (Claude), `.cursor/rules` (Cursor) o `AGENTS.md` (Codex/opencode). Si tu herramienta usa otro nombre, duplica este archivo como `MUSE.md`.

## Qué es
Traductor de circuitos cuánticos de formato **Quirk** (`https://algassert.com/quirk#circuit=...`) a **OpenQASM** (versiones 2.0 y 3.0, por defecto 3.0) como lenguaje pivote y, desde allí, a ecosistemas como IBM Qiskit, AWS Braket y Xanadu PennyLane.

## API de librería: `translate_circuit(payload)`
Función core de `qtrans/core.py`: recibe un payload JSON (dict o cadena) y devuelve `{"input": <eco normalizado>, "output": ...}` (refleja las carpetas `input/`→`output/`). Sección de código: `_QASM_MODIFIER_RE:980`, constantes del contrato `_TRANSLATE_*` (`982-998`), helpers `_unknown_keys:1001`/`_resolve_circuit_url:1015`/`_qasm_gate_summary:1051`/`_zx_calculus_result:1094`/`_require_keys:1124`/`_validated_bool:1147`/`_validated_int:1165`/`_normalize_translate_input:1184`, etapas opcionales `_image_qasm_base64:1298`/`_image_quirk_base64:1328`/`_comparison_markdown:1349`, `_translate_circuit_entry:1372`, `translate_circuit` (~línea 1483).
- **Entrada** (`input`, única clave permitida del payload): exactamente uno de `url` | `json` | `circuits` (lote: lista de `{name?, url|json, offset?}`); más `offset`, `qasm_version` ('2.0'|'3.0'), `provider` (str o lista; alias canónicos), `shots`, `preserve_custom_gates`, `zx: {enabled, time, timeout}`, `images: {quirk, qasm, composer, capture_timeout}`, `comparison`.
- **Salida** (`output`): dict si es único, **lista** de dicts si es lote. Claves por circuito: `qasm` (`code`, `version`, `lines`, y `gates.custom`/`gates.native` = `{count, names}` únicos ordenados; el conteo se hace sobre el QASM 3.0 previo a bajar a 2.0, para que sea estable), `migrated_code` (dict con clave `<PROVIDER_DIRECTORY>_code`, p. ej. `ibm_qiskit_code`/`aws_braket_code`/`xanadu_pennylane_code`), `zx_calculus_result` ('equivalente'|'no-equivalente'|'no-comprobado'; null si `zx.enabled=false`), `circuit_info` (n_qubits, n_cols, gates), `img` ({quirk,qasm,composer} en base64 PNG; quirk = Selenium, off por defecto), `comparison_doc` (Markdown inline), `errors` ([{stage,message}] de etapas opcionales fallidas; nunca tumban la traducción). **En modo lote cada objeto incluye además `name`; el circuito único no lleva `name`.**
- Claves no solicitadas = siempre presentes con `null`. Payload inválido (claves desconocidas, faltantes, mal tipadas, fuera de rango) → `ValueError`; la traducción/migración propaga sus excepciones. Tests: `test/test_translate.py` (ejecutar con `unittest discover`; el import como `test.test_translate` choca con la stdlib `test`). Ejemplo imprimible: `test/test_translate_lib.py`.

## Reglas de traducción
- `offset` desplaza todos los índices `q[i+offset]`; `n = max(_column_extent(col))+offset` (el extent cuenta la altura de custom gates y de las QFT nativas).
- `•`+`X`/`Z`/`Y` → `cx`/`cz`/`cy` (1 control), `ccx` (2), `Swap` → `swap`. `X^½` etc → `rx`/`ry`/`s`/`t`.
- Campo `gates` en la URL:
  - `{"id":"~rvcr","name":"MultiX","circuit":{"cols":[["•","•","X","•"]]}}` → expandible. Mapa por `id` y `name`, sufijo `:k` para gates multi-columna (`~abc:1`). Soporta anidamiento (profundidad ≤10).
- URLs Quirk requieren JSON estricto con `"` dobles; para `href` usar `encode_quirk_url`.
- Versión: `quirk_to_qasm(url, offset, qasm_version='3.0')` acepta `'2.0'`/`'3.0'`; `'2.0'` transpila vía Qiskit a `u1/u2/u3/cx`. La celda de generación y las celdas de migración leen `QASM_VERSION` desde `.env` (`QTRANS_QASM_VERSION`, default `'3.0'`) con `load_dotenv()`; la celda de generación escribe `_v2.0.txt`/`_v3.0.txt` y las celdas posteriores quitan el sufijo con `strip_qasm_version`.
- Celdas de migración (sección «Migración de circuitos a ecosistemas / lenguajes concretos») = **dos celdas**:
  1. **Carga** — `cargar_circuito_qasm(qasm_str, provider, qasm_version, shots, preserve_custom_gates, native=True)` (`qtrans/utils/qutils.py:1462`) hace el `loads()` por proveedor y deja `circuitos_cargados[provider][nombre]`. Filtran estrictamente `path.name.endswith(QASM_VERSION_SUFFIX + ".txt")`; si la corrida actual no tiene `algorithms_qasm` usan (con aviso) el run más reciente que sí lo tenga, y si no hay ninguno fallan con un error accionable (hay que correr la celda de generación de OpenQASM). Comportamiento por proveedor: **qiskit** → parser nativo (`qasm2.loads`/`qasm3.loads` por cabecera, 100 % de los archivos); **braket** → `Circuit.from_ir` nativo (quitando `include "stdgates.inc"`) con respaldo automático porque no conoce la puerta `p` (~36/53); **pennylane** → **siempre** vía script migrado (`provider_python_source`+`exec` → `QNode`), porque `qml.from_qasm` exige `pennylane-qiskit` y `qml.from_qasm3` no acepta `qreg` indexados. Tipos uniformes por proveedor: `QuantumCircuit` / `Circuit` / `QNode`.
  2. **Generación** — para cada proveedor **cargado** llama `provider_python_source(...)`, hace `compile()` y escribe `output/run_*/migrated_circuits/<subcarpeta>/<nombre>.py`, donde `<subcarpeta>` sale de `PROVIDER_DIRECTORY` (`ibm_qiskit` / `aws_braket` / `xanadu_pennylane`).
  - Proveedores: `providers_from_env()` lee `QTRANS_PROVIDERS` (alias válidos: `ibm`, `aws`, `xanadu` → `qiskit`, `braket`, `pennylane`) y si falta cae a `QTRANS_TARGET_PROVIDERS`, default `qiskit`. Ambas celdas leen además `QASM_VERSION` (`QTRANS_QASM_VERSION`, default `'3.0'`; `ValueError` si no es `'2.0'|'3.0'`), `QTRANS_SHOTS` y `QTRANS_PRESERVE_CUSTOM_GATES` con `load_dotenv()`.
  - La celda de IBM Composer usa `migrated_circuits/ibm_qiskit` (con respaldo al nombre legado `qiskit`); las celdas de imágenes/comparación definen su propia `load_qasm_circuit(text)` local (dispatch por cabecera `OPENQASM 2.0` → `QuantumCircuit.from_qasm_str`, `3.0` → `qasm3.loads`, fallback). No usar `qasm3.loads` directo sobre `_v2.0.txt` (falla con `QASM3ImporterError: '2,0: non-stdgates imports not currently supported'`).
- Puertas en los generadores de migración (`qtrans/utils/qiskit_utils.py`, `qtrans/utils/braket_utils.py`, `qtrans/utils/pennylane_utils.py`): `u1/u2/u3` (u2 lleva 2 params φ,λ: `lam = parameters[2] if name=="u3" else (parameters[1] if name=="u2" else parameters[0])`); ángulos fijos `rx_*/ry_*/rz_*` y fases fijas `cp_*/cu1_*` (incl. fracciones `_pi_`, p. ej. `cU_pi_2`, `cp_7_pi_8`) vía `_angle_to_expr` (emite `math.pi/2`, `3*math.pi/4`, …, definido en `qutils.py:1213`); Qiskit mapea `u1/u2/u3` a puertas nativas con `_native_gate_for_u` (h/x/y/z/s/sdg/t/tdg/sx/id) para no emitir `circuit.u(...)` en gates estándar, y usa `PhaseGate`/`UGate` (imports dinámicos `gate_imports` from `qiskit.circuit.library`) para `.control(k)`.
- Utilidades auxiliares (sección «Funcionalidades Auxiliares», ahora en `notebooks/QTrans_Utils.ipynb`, separada de `QTrans.ipynb` por prolijidad): `mostrar_url_quirk(url)`/`formatear_url_quirk(url)`/`limpiar_url_quirk(url)` — recibe **directamente la URL cruda** de Quirk (con `circuit=<JSON>`, p.ej. `url_quirk_cruda`) aunque venga **mal formateada** (con `\` y `\"` sobrantes al pegar el JSON): `limpiar_url_quirk` quita comillas externas, desescapa `\"`/`\'`, elimina backslashes sobrantes y recorta desde `https://`; luego `encode_quirk_url` percent-encodea para que renderice en algassert.com/quirk. Devuelve/muestra un enlace `<a ...>Abrir en Quirk</a>` y valida round-trip (`parse_quirk_url` + `quirk_circuit_info`). En el JSON el `•` es U+2022 real.
- `qasm_to_zx_graph` admite gates con parámetros `rx/ry/rz/p/u1/u2/u3/u` y declaraciones `qreg` (QASM 2.0) o `qubit` (QASM 3.0).
- **QFT nativa de Quirk**: token `QFTn` / `QFTn†` (daga como sufijo; también se tolera prefijo `†QFTn`), regex `_QFT_TOKEN_RE` (`qtrans/utils/qutils.py:105`). **En Quirk el id canónico de la inversa es `QFT†n`** (`setSerializedId("QFT†" + span)` en `FourierTransformGates.js`); las variantes `QFTn†`/`QFT^†n` no existen allí y Quirk las pinta como compuerta "parse error". `canonicalize_quirk_url` (`qtrans/utils/url_utils.py`) reescribe esas variantes a `QFT†n` y se aplica en `capture_quirk_circuit` y en `encode_quirk_url`; `input/qft_algorithms.json` usa la forma canónica. Regresión: `test/test_qft_canonical.py`. Se emite **siempre** como declaración `gate QFTn a,b,c {…}` (H + `cp(pi/2**k)` + `swap`, descomposición estándar con swaps, ≡ DFT en convención little-endian de Qiskit) y nombre inverso `QFTn_dg`; el sitio de uso es `QFTn q[i],…` (soporta `ctrl @ QFTn …`). `n` se calcula con `_column_extent`. En ZX se expande con `_zx_append_qft`.
- **`preserve_custom_gates`**: `provider_python_source(qasm, provider, qasm_version, shots, preserve_custom_gates=False)` y los tres generadores lo aceptan. `true` → cada compuerta custom/nativa (incl. `QFTn`, `cu1_*`, `cU*`) se define **una sola vez** como función local (`def nombre(circuit, w0, w1…)` en Qiskit/Braket, sin `circuit` en PennyLane) y se llama en su lugar; `false` → se expande en línea. `_unquote_parameters` quita las comillas que `!r` añade alrededor de los placeholders `wN`. En `qtrans/core.py`: `QTRANS_PRESERVE_CUSTOM_GATES`/`DEFAULT_PRESERVE_CUSTOM_GATES`, param `preserve_custom_gates` en `run_pipeline`/`_generate_provider_files`, CLI `--preserve-custom-gates`/`--no-preserve-custom-gates` y clave en el resumen.

## `quirk_circuit_info(url)`
Retorna `{n_qubits, n_cols, gates, custom_gates, custom_gate_ids, custom_gate_names, n_custom_gates, custom_gates_gates, custom_gates_info}`. `n_qubits` es efectivo (incluye altura de gates usados).
